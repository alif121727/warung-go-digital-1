Warung Go Digital

Kebijakan Privasi

Berlaku sejak 12 November 2026 · Berlaku untuk aplikasi Android/iOS dan situs web Warung Go Digital

Warung Go Digital adalah aplikasi pencatatan penjualan, pendapatan, dan lokasi jualan harian untuk pemilik warung dan UMKM, beserta panel pengelola untuk merekap laporan mitra. Kami merancang aplikasi ini agar data Anda tetap di perangkat Anda.

Ringkas

  • Kami tidak memiliki server yang menyimpan data warung Anda secara bawaan.
  • Kami tidak memakai iklan, analitik, atau pelacak pihak ketiga.
  • Kami tidak mengumpulkan nama, nomor telepon, atau kontak Anda.
  • Lokasi hanya diambil saat Anda menekan tombol "Ambil titik peta", dan tetap di perangkat.
  • Anda dapat menghapus seluruh data kapan saja dari dalam aplikasi.

1. Data yang disimpan

Aplikasi menyimpan data berikut hanya di penyimpanan lokal perangkat (untuk aplikasi: penyimpanan internal aplikasi; untuk situs: localStorage peramban):

  • Identitas warung yang Anda isi sendiri: nama warung, nama pemilik, nomor WhatsApp, alamat, dan jenis usaha.
  • Catatan harian: tanggal, omzet, pengeluaran, jumlah transaksi, rincian barang, dan catatan bebas.
  • Titik peta (opsional) bila Anda menekan "Ambil titik peta".

Data ini tidak dikirim ke kami. Aplikasi tetap berfungsi penuh tanpa internet.

2. Izin perangkat

  • Lokasi (perkiraan) — hanya dipakai saat Anda menekan tombol "Ambil titik peta", untuk menyimpan koordinat warung. Boleh ditolak; fitur lain tetap berjalan.
  • Penyimpanan berkas — dipakai saat Anda menyimpan berkas ekspor (CSV, cadangan JSON, poster) atau membagikannya lewat menu Bagikan Android/iOS.

3. Membagikan data (tindakan Anda sendiri)

Aplikasi tidak mengirim data apa pun secara otomatis. Data hanya keluar bila Anda sendiri yang melakukannya, yaitu lewat:

  • tombol Kirim — berkas laporan dibuat di perangkat, lalu Anda lampirkan ke WhatsApp;
  • tombol Bagikan — berkas dibagikan ke aplikasi lain yang Anda pilih;
  • tab Sinkron (opsional) — bila Anda mengisi alamat server, catatan dikirim ke alamat tersebut. Server itu milik pengelola Anda, bukan milik kami. Fitur ini nonaktif bila alamat dibiarkan kosong.

4. Pihak ketiga

Aplikasi tidak menyertakan iklan, SDK analitik, atau pustaka pelacak. Situs web memuat huruf (font) dari Google Fonts; permintaan itu tunduk pada kebijakan privasi Google. Selain itu tidak ada layanan pihak ketiga lain.

5. Anak-anak

Aplikasi ini ditujukan untuk pemilik usaha dewasa (18 tahun ke atas), bukan untuk anak-anak. Kami tidak sengaja mengumpulkan data anak.

6. Menghapus data Anda

  • Di aplikasi: buka menu Cadangan/Setelan lalu pilih hapus data, atau hapus aplikasi dari perangkat.
  • Di situs: bersihkan data situs (localStorage) dari pengaturan peramban.
  • Karena kami tidak menyimpan data Anda di server, tidak ada permintaan penghapusan yang perlu diajukan ke kami.

7. Keamanan

Data tersimpan di dalam ruang terbatas milik aplikasi pada perangkat Anda. Kami sarankan mengunci layar perangkat dan memakai fitur cadangan aplikasi untuk menyimpan salinan aman pada perangkat atau akun cloud pribadi Anda.

8. Perubahan kebijakan

Bila kebijakan ini berubah, kami akan memperbarui tanggal di atas dan menampilkan versi terbaru di halaman ini.
